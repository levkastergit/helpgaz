# HelpGaz

Программа для Windows: сверяет папки ИТД, скачанные с сайта, с шаблонами и с договорами. Отличия попадают в журнал находок, по которому потом правятся шаблоны.

## Как пользоваться

1. Скачайте `HelpGaz.exe` со страницы [Releases](../../releases/latest) и запустите. Установка не нужна.
2. Войдите под учётной записью сайта.
3. Перетащите в окно папку объекта или общую папку со всеми объектами и нажмите «Проверить».
4. На вкладке «Папки» виден итог по каждой папке. Если договор не определился, нажмите «Выбрать договор…».
5. На вкладке «Находки» одинаковые отличия из разных папок собраны в одну строку. Самые частые находятся сверху. Каждой находке можно поставить статус.

## Что проверяется

| Проверка | Что находит |
| --- | --- |
| Текст | Изменённый, добавленный или удалённый постоянный текст шаблона |
| Значения | Адрес, ФИО, даты и другие подставленные данные, которые отличаются от того, что сайт выдаёт по договору сейчас |
| Оформление | Шрифт, размер, жирность, курсив, подчёркивание, выравнивание, отступы, интервалы |
| Разметка страниц | Размер и поля страницы, ориентация, разрывы страниц |
| Незаполненные места | Оставшиеся `{теги}`, `undefined`, пустые поля, старые поля Word с постоянным текстом |
| Сверка внутри папки | Значение, которое в одном документе отличается от остальных |

Для папки без договора значения не сверяются: остальные проверки работают, а внутри папки сравниваются только адрес и ФИО.

Как определяется договор:

- `ITD_Files_<число>` — архив кнопки «Скачать все», число равно id договора на сайте. Если договора с таким id на сайте нет, в столбце «Договор» так и написано: «Договора #940 нет на сайте». Проверить вручную можно по адресу `/itd/<id>` на сайте.
- Другие названия разбираются по фамилии с инициалами, организации, составному номеру договора или адресу. Договор выбирается только при уверенном совпадении, иначе предлагается список.
- Подпапка с общим именем («Новая папка», «Акты») берёт договор у родительской папки, не выше двух уровней.

Сертификаты, `.dwg` и другие файлы не проверяются. `.docx` с незнакомым именем попадает в журнал как «Неизвестный документ».

## Статусы находок

- **Новая** — ещё не разобрана.
- **Править шаблон** — отличие нужно перенести в шаблон.
- **Это норма** — больше не показывать, решение сохраняется и после повторных проверок.
- **Исправлено** — если отличие встретится снова, находка опять станет новой.

Повторная проверка папки заменяет её старые результаты, поэтому дублей не возникает.

## Где лежат данные

Журнал и сессия находятся в `%LOCALAPPDATA%\HelpGaz`. Кнопка «Папка журнала» открывает это место.

- `findings.json` — журнал находок, его можно передать для правки шаблонов.
- `session.bin` — токен сайта, зашифрованный средствами Windows. Пароль не сохраняется.

В этом репозитории нет шаблонов, документов и персональных данных: программа получает их с сайта после входа. Имена документов в коде хранятся как хэши.

## Обновления

При запуске программа проверяет GitHub Releases. Если вышла новая версия, она скачивает её, сверяет SHA-256 и перезапускается. Сборка, запущенная не из релиза, не обновляется.

## Разработка

Нужен .NET 8 SDK.

```
dotnet test tests/HelpGaz.Tests/HelpGaz.Tests.csproj
dotnet run --project src/HelpGaz.App
```

Релиз выпускается пушем тега `vX.Y.Z`: GitHub Actions прогоняет тесты, собирает один exe и публикует его вместе с контрольной суммой.

Если на сайте появились новые штатные документы ИТД, обновите таблицу документов: `python tools/build_catalog.py <путь к KssWorkSite>`. Пользовательские шаблоны с сайта подхватываются автоматически.

Переменные окружения для тестов: `HELPGAZ_SITE` (адрес сайта), `HELPGAZ_DATA` (папка данных), `HELPGAZ_NO_UPDATE` (отключить обновление).
